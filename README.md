# 🔷 Holo AI Companion v5

A futuristic **JavaScript-powered holographic AI interface simulation** built using HTML5 Canvas, CSS, and Vanilla JavaScript.

This project creates a sci-fi hologram companion featuring animated particles, glowing effects, interactive eye tracking, and a real-time holographic projection system.

---

# ✨ Features

## 🌌 Holographic Projection System

- Real-time hologram rendering using HTML5 Canvas
- Neon glow effects
- Transparent holographic body simulation
- Flickering distortion effects
- Scanline projection effect


## 👁️ Interactive AI Vision

- Eye movement tracking
- Cursor-following behavior
- Real-time interaction with user movement


## ⚡ Particle Energy System

- Dynamic floating particles
- Circular energy field
- Animated particle movement
- Holographic atmosphere effects


## 🤖 AI Character Simulation

- Floating idle animation
- Breathing motion effect
- Futuristic HUD interface
- Digital companion concept


---

- Canvas API
